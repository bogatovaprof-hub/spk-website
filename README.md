# Прототип сайта СПК ТРЕЙД

Адаптивный многостраничный прототип по утверждённому светлому референсу. Первая версия предназначена для визуального согласования и точечных правок перед переносом на Tilda.

## Статус версии

- 21 обычная страница и отдельная `404.html`;
- статическая сборка Astro;
- формы только проверяют поля и файлы в браузере;
- введённые данные и выбранные файлы не отправляются и не сохраняются;
- на всех страницах установлен `noindex`;
- домен, корпоративная почта, аналитика и реальный обработчик форм не подключены.

## Локальный запуск

Требуется Node.js 24.19.0 или совместимая версия 24+.

```bash
npm install
npm run dev
```

Локальный адрес по умолчанию: `http://localhost:4321/`.

## Проверки и сборка

```bash
npm run check
npm run build
npm run test:smoke
```

Статическая сборка создаётся в `dist/`. Smoke-тесты используют Playwright Chromium. На новой машине браузер для тестов устанавливается отдельно:

```bash
npx playwright install chromium
```

## Структура

- `src/pages/` — маршруты;
- `src/components/` — общие блоки и формы;
- `src/data/` — тексты, меню, услуги и состояния прототипа;
- `src/styles/` — дизайн-токены и общие стили;
- `public/images/`, `public/icons/` — кропы утверждённого референса;
- `reference/home-approved.png` — визуальный эталон;
- `docs/` — содержание и критерии приёмки;
- `qa/REPORT.md` и `qa/screenshots/` — фактический отчёт и контрольные снимки.

Тексты меняются в `src/data/*.json`. Общая палитра и типографика — в `src/styles/tokens.css`. Компоновка и адаптивность — в `src/styles/global.css`.

## GitHub Pages

Конфигурация поддерживает проектный адрес вида `https://OWNER.github.io/REPO/`. Для локальной проверки подпапки:

```powershell
$env:SITE_ORIGIN='https://OWNER.github.io'
$env:SITE_BASE='/REPO'
npm run build
Remove-Item Env:SITE_ORIGIN
Remove-Item Env:SITE_BASE
```

Workflow `.github/workflows/deploy.yml` запускается только вручную. До запуска в настройках репозитория нужно выбрать Pages → Source → GitHub Actions. Само наличие workflow не публикует сайт.

Для будущего клиентского домена потребуется убрать project `base`, задать подтверждённый домен как `SITE_ORIGIN`, согласовать DNS и только затем подключать форму и аналитику. В текущей версии этого нет.

## Ограничения материалов

Изображения — точные небольшие кропы из растра 1122 × 1402, а не полноразмерные оригиналы. Векторного логотипа и реальных карточек проектов нет. Утверждения об опыте сохранены из клиентского текста и перед коммерческой публикацией требуют подтверждения. Контакты в макете неактивны: домены `spk-traid.ru` и `spk-trade.ru` расходятся в исходниках.
