# Задание на прототип СПК ТРЕЙД

Полная авторитетная постановка задачи находится в корне репозитория: [`SPK_FULL_SPEC.md`](../SPK_FULL_SPEC.md).

Для реализации также обязательны:

- `DESIGN_SYSTEM.md` — визуальная система;
- `ASSETS_GUIDE.md` — происхождение и ограничения изображений;
- `ACCEPTANCE.md` — критерии фактической проверки;
- `src/data/*.json` — тексты и маршруты;
- `reference/home-approved.png` — утверждённый визуальный эталон.

Версия v1 — многостраничный статический прототип для GitHub и последующих точечных правок. Формы ничего не отправляют, домен и корпоративная почта не подключаются, неподтверждённые факты и проекты не добавляются.
